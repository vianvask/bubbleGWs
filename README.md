# bubbleGWs

Gravitational wave spectra from bubble collisions in strongly supercooled first-order phase transitions, computed in the thin-wall limit with cosmic expansion included.

The code nucleates bubbles in a periodic box with an exponential nucleation rate, tracks the collisions of the bubble walls, and solves for the resulting gravitational wave spectrum in the envelope and bulk flow approximations, in either an expanding or a static background.
